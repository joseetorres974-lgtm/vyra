# VYRA

Web app de entrenamiento inteligente con IA

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/joseetorres974-lgtm/vyra)

## Descripcion

VYRA es una web app de entrenamiento para fuerza e hipertrofia con seguimiento de series, analisis de progreso y un coach de IA integrado que genera rutinas personalizadas.

## Funcionalidades

- Registro de entrenamientos con series, peso, reps y RIR
- Biblioteca de ejercicios con filtros por musculo y equipamiento
- Progreso y graficas de volumen, PRs y frecuencia
- Ia Coach para generar rutinas y analizar progreso
- Modo oscuro/claro
- PWA instalable

## Stack Tecnologico

- **Frontend**: Next.js 15, TypeScript, TailwindCSS, ShadCN UI
- **Backend**: Supabase (PostgreSQL + Auth + Storage)
- **Ia**: OpenAI GPT-4o API
- **Payments**: Stripe
- **Hosting**: Vercel
